# CUDA environment for dataset-wide XAI research

`requirements.txt` is the base CPU environment. It deliberately does not pin a universal CUDA wheel, because the correct PyTorch package depends on the GPU driver, CUDA runtime, and target machine.

1. Create the usual virtual environment and install `requirements.txt`.
2. Reinstall `torch` and `torchvision` with the CUDA-compatible command generated by the [official PyTorch installer selector](https://pytorch.org/get-started/locally/).
3. Verify the selected environment before starting a long run:

```powershell
.\.venv\Scripts\python.exe -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'No CUDA device')"
```

Only run with `--device cuda` after this prints `True`. `--device auto` uses CUDA when available and otherwise runs the PyTorch XAI portion on CPU. It never pretends that a CPU-only PyTorch build is GPU-enabled.

Example full-run command:

```powershell
.\.venv\Scripts\python.exe scripts\run_research.py --model resnet50 --device cuda --run-id thesis-resnet50-01
```

If a run stops, repeat the same command with `--resume`. The runner validates the run ID, model, checkpoint, seed, device, and Quantus configuration before it skips completed `sample × XAI method` combinations.
